# EDITORS.GroupBuddy — Group & Spatial Containment Buddy

**Wiki:** [Documentation/README.md](Documentation/README.md) — principles, architecture, delivery.

Group & Containment Buddy: organize hierarchical spatial groupings (Site -> Campus -> Building -> Room -> Rack -> Bay), configure boundary paddings, group nesting, and architectural zoning colors.

| | |
|---|---|
| **Opens** | the OS shell (Design → Containment & Architecture), or `index.html` standalone |
| **Build** | none — plain web files; `npm test` |
| **Ships** | baked into WEB.Frontend-Assets (`up-stack.sh WEB.Frontend-Assets`), served at `:8080/Softapps/EDITORS/EDITORS.GroupBuddy/` |
